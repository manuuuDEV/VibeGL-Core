# Security Policy

## Supported Versions

We currently provide security updates for the `main` branch and the latest stable release.

## Reporting a Vulnerability

If you discover a security vulnerability within VibeGL-Core, please **do not open a public issue**. 
Instead, send a private message to the maintainers or use the GitHub Security Advisory "Report a vulnerability" feature if enabled on the repository.

Please include:
- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact and affected components.

We will acknowledge your report within 48 hours and work with you to resolve the issue promptly before public disclosure.
